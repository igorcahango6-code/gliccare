# GlicCare

App web de acompanhamento de glicemia, insulina, alimentação, atividade física e mais.

Veja `PROJETO.md` para a definição de requisitos e o plano de implementação em `.claude/plans` (ou peça ao Claude Code para consultar o plano ativo).

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
